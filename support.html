SUPPORT

Help keep GradeLab accurate.

Use the Request an update control inside GradeLab to prepare a report for a missing class, newer syllabus, incorrect category, or assignment-display problem.

When reporting an issue

  • Include the course number and semester.
  • Describe the incorrect category or calculation.
  • Attach or link the current official syllabus when possible.
  • Never send your password, browser cookies, or authentication codes.

Troubleshooting

Make sure you are signed into CMU Canvas in Chrome, then reopen GradeLab and use Refresh Canvas + Gradescope. Gradescope details are added when a Gradescope session launched through Canvas is available.
